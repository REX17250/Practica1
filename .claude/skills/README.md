# Skills de Claude Code para este proyecto

Cada skill vive en su propia subcarpeta dentro de `.claude/skills/`, con un
archivo `SKILL.md` que describe cuándo y cómo debe usarse.

```
.claude/skills/
  nombre-del-skill/
    SKILL.md
```

Una vez creado, el skill aparece disponible para invocarse como `/nombre-del-skill`
dentro de Claude Code en este repositorio.
